Installation
============

This section provides instructions on how to install the software.

Requirements
------------
The software requires the following:

- Python 3.9 or higher (tested on 3.10 and 3.12)
- pandas 2.1.4 to 3.x
- numpy 1.25 to 2.x
- SQLAlchemy 1.4 to 2.x

CI tests both ends: the oldest supported set (pandas 2.1.4, numpy 1.26, SQLAlchemy 1.4, as goblin_lite pins) and the
latest releases.


Install with pip
----------------
You can install the package using pip:

```bash

    pip install landcover_lca
```

Install from Source
-------------------
To install from source using pip and git:

```bash
    pip install git+https://github.com/GOBLIN-Proj/landcover_lca.git@main
```
